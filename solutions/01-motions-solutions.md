# Chapter 01 练习参考解决方案

## 高效命令序列示例

### 清理段落 3
1. 移动到 "很 多" ： `f很` 或使用 `w` 多次
2. `ciw` 修改第一个 "很多" 为 "很多"
3. `dW` 或 `dw` 删除多余空格
4. 更好的做法：使用 `:s/\s\+/ /g` 或手动 `ciw` + motions

### 最佳实践
- 修改单词：`ciw` (光标在单词任意位置)
- 修改引号内：`ci"`
- 修改括号内：`ci(` 或 `ci{`
- 修改 tag 内：`cit`
- 删除到行尾：`d$`
- 复制段落：`yap`

### 宏示例 (为后续章节准备)
`qa` 然后执行一系列 motions 和 edits，然后 `q` 录制。之后 `@a` 重复。

**关键心得**：
- 尽量使用 text objects 而不是字符级移动 (`ciw` 胜过 `b` `cw`)
- `f` / `t` + `;` 是快速定位利器
- 标记 (`ma` `` `a ``) 在大文件 中非常有用
