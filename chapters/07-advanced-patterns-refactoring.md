# Chapter 07: Advanced Patterns & Code Refactoring

> 将所学应用于实际重构。使用宏、global、operators 组合进行复杂编辑。

## 高级技巧

- 组合使用 `:g` + macro
- 结构化编辑 (surround 概念，即使无插件也可模拟)
- 批量重命名、重构函数
- 使用 visual block (Ctrl-v) 编辑多列
