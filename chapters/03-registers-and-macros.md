# Chapter 03: Registers & Macros - 寄存器与宏录制

> 本章重点：弄清每次 yank/delete 进了哪个剪贴板，并在 `.` 不够用时把一串操作录成宏。寄存器和宏是同一件事：把文本（或按键）放进一个带名字的盒子。

上一章的 `d` / `y` 已经在往寄存器里放内容；`.` 已经能重复「上一次改动」。本章只多问两件事：盒子有几个？一串动作怎么一起重复？

## 3.1 你已经在用寄存器

`yy`、`dd`、`p` 默认走 unnamed 寄存器 `""`。你一直在用它，只是没点名。

做一个小实验（本章任意一行即可）：

1. `yy` 复制当前行
2. 移到另一行，`dd` 删除
3. `p` 粘贴

贴出来的通常是刚删的那一行，不是刚才 yank 的那一行。因为 `dd` 覆盖了 `""`。

这时只要记住两个补救：

- `"0p`：贴回**最后一次 yank**（`0` 是 yank 专用，不会被 `dd` 抢走）
- `"_dd`：删除进黑洞，不污染 `""` 和 `"0`

日常够用的寄存器：

| 寄存器 | 作用 | 什么时候用 |
| ------ | ---- | ---------- |
| `""` | 默认 unnamed | `y` / `d` / `p` 不写名字时 |
| `"0` | 最后一次 yank | 删过东西之后还想贴刚才复制的 |
| `"_` | blackhole | 清理垃圾文本，不想弄脏剪贴板 |
| `"+` | 系统剪贴板 | 和 Cursor / 浏览器 / 终端互拷 |

**Cursor 用户注意**：在 Cursor 的 Vim 模式下，`"+y` / `"+p` 通常就是系统剪贴板。从编辑器拷到外面，或从外面贴回来，优先用它，而不是指望 unnamed。

查看当前盒子：`:reg`（可先看 `""`、`0`、`+`）。

## 3.2 命名寄存器：多个剪贴板

需要同时拿着两段文本时，自己指定盒子：

- `"ay` / `"ayiw` / `"ayap`：yank 到寄存器 a
- `"ap`：粘贴 a
- `"by` / `"bp`：另一段放 b

小写字母**覆盖**该寄存器；大写 `"Ay` 是**追加**到 a 末尾（现在知道即可，练习里不必用）。

建议养成习惯：临时碎片用 `"a` `"b`，和系统交换用 `"+`，清理用 `"_`。不必一次记完 `"1`–`"9` 和 `"/`，它们在文末选读。

## 3.3 从 `.` 到宏

`.` 只重复上一次**改动**（例如刚做完的 `ciw`）。下面这种任务它帮不上忙：

- 行首插入 `- `
- 再跳到下一行行首
- 对后面每一行做同样的事

这是两步，需要把按键序列录下来。宏就存在寄存器里，所以录到 a 用 `qa`，回放用 `@a`：

1. `qa` — 开始录制到寄存器 a
2. 做你要重复的 motions / edits（用第 1–2 章的 `I`、`ciw`、`j` 等）
3. `q` — 停止录制
4. `@a` — 执行宏 a
5. `@@` — 再执行一次「刚才那个宏」

**让宏可回放的三条**（比记住 `100@@` 更重要）：

1. 录之前先空手走一遍，确认每一步都是相对动作（`j`、`^`、`ciw`），不要依赖这次碰巧的列号。
2. 结束时，光标必须落在**下一处同类位置**。否则 `@a` 会对着错误的地方打。
3. 先 `@a` 试一次，对了再用 `@@` 或 `7@a`。录错了：`u` 撤销，重新 `qa` 覆盖即可。

录完后执行 `:reg a`，或在空行 `"ap`。你会看到一串按键字符——**宏就是寄存器里的文本**。这就是寄存器和宏放在同一章的原因。

## 3.6 选读（可跳过）

这些命令是真的，但不是本章过关项：

- `"1`–`"9`：较大删除的历史；小删除（不够一行）往往进 `"-`。需要时 `:reg` 里看一眼即可。
- `"/`：上次搜索模式。第 4 章用 `/` 之后会自然碰到。
- `qA`：向已有宏 a **追加**按键（录漏了一步时有用）。
- `100@a` / `100@@`：重复很多次。行数不够或宏不可重复时，会在中途停下，这是保护而不是故障。
- Visual 选中若干行后 `:norm @a`，或 `:%norm @a`：对每一行跑一遍 Normal 命令。第 7 章做批量重构时再练。
