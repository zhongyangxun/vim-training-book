# Chapter 05: Buffers, Windows 与 Tabs

> 高效管理多个文件是熟练 Vim 用户的标志。

## 命令概览

- `:e file` / `:bn` / `:bp` : buffer 导航
- `:ls` 或 `:buffers` : 列出 buffers
- `Ctrl-^` : 切换到上一个 buffer
- `:split` `:vsplit` : 分屏
- `Ctrl-w` + 方向 : 窗口切换
- `:tabnew` `:tabn` `:tabc` : 标签页

**窗口调整**： `Ctrl-w _` 最大化, `Ctrl-w =` 均分。
