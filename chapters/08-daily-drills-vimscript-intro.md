# Chapter 08: Daily Drills 与 Vimscript 入门

> 熟能生巧。建立每日练习 routine，并了解 Vimscript 基础以进一步定制。

## 每日 Drill (15 分钟)

1. 打开 cheat-sheet.md 复习 5 个命令
2. 在 exercises/ 文件中练习 motions + operators 10 次
3. 录制并优化一个宏
4. 使用 `:s` 和 `:g` 进行批量编辑
5. 尝试不看键盘完成一个完整重构

## Vimscript 入门

- `nnoremap` / `inoremap` : 映射
- `set` 命令
- 简单函数和 autocmd
- 参考 example.vimrc

**进阶建议**：
- 阅读 Vim Galore
- 尝试安装少量插件 (surround.vim, vim-fugitive)
- 参与开源项目使用 Vim 编辑
